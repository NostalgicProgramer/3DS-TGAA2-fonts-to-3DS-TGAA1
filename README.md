# English
# 3DS-TGAA2-fonts-to-3DS-TGAA1
A tool for porting fonts from TGAA2 to TGAA1

Original code by: Akoi89 (link to profile: https://github.com/Akoi89)

# How to use the tool

Run the project and select the TGAA2 font, followed by the TGAA1 font so that the TGAA2 font adjusts to the height parameters of the first TGAA game. Then, click save to create the destination file and select "convert file." You will then have a font with more characters, making it easier to translate the 3DS version of TGAA1.

Many thanks to Akoi89 for creating the original code used for this tool.
